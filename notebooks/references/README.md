# Notebook tham khảo

Các notebook tham khảo dùng để đối chiếu phương pháp và nguồn gốc. Hai mục chưa xác minh giấy phép được dẫn tới trang Kaggle. Quy trình tái lập nghiên cứu dùng các notebook chính và dữ liệu JPX gốc.
